## Overview

**Turing Wings** is an AI-native engineering accelerator and multi-agent development ecosystem designed to transform how modern engineering teams learn, build, collaborate, and ship production software.

The platform combines:

* AI-powered engineering workflows
* Multi-agent development systems
* Real-time world models
* Production cloud infrastructure
* Immersive engineering cohorts
* High-speed buildathons and hackathons
* Dynamic event experiences
* Automated engineering workflows

The platform follows a unified visual language built around a **cream-grey canvas, Cascadia Code typography, green engineering accents, and high-contrast product surfaces**.

# 02 — Dynamic Event Experience Engine

Turing Wings includes a reusable event-page engine capable of generating completely different visual experiences from a shared architecture.

Each event can be configured through a dedicated theme system.

## Available Themes

| Theme                  | Experience                                                |
| ---------------------- | --------------------------------------------------------- |
| **Cyberpunk Neon**     | Perspective grids, neon geometry and digital motion       |
| **Space Odyssey**      | Starfields, orbital paths and constellation systems       |
| **Corporate Pro**      | Blueprint grids, structured layouts and executive visuals |
| **Premium 3D Spatial** | Interactive floating wireframe geometry                   |
| **Minimal Light**      | Clean canvas, dot matrices and subtle motion              |
| **AI Future**          | Neural networks, nodes and intelligent particle systems   |

### Theme Architecture

```text
Event Portal
     │
     ▼
Template Registry
     │
     ├── Cyberpunk
     ├── Space
     ├── Corporate
     ├── Spatial 3D
     ├── Minimal
     └── AI Future
             │
             ▼
       Canvas Engine
```

Each theme operates independently while sharing the same event infrastructure.

# Design System

Turing Wings follows a consistent visual system across the platform.

## Color Tokens

```css
:root {
  --bg-primary: #FAF8F5;
  --bg-dark: #090909;
  --accent-green: #22C55E;
  --text-main: #111111;
}
```

| Token              | Value     | Usage                          |
| ------------------ | --------- | ------------------------------ |
| Primary Background | `#FAF8F5` | Main application canvas        |
| Dark Surface       | `#090909` | High-contrast sections         |
| Accent Green       | `#22C55E` | Primary actions and highlights |
| Main Text          | `#111111` | Typography and content         |

## Typography

```css
font-family: "Cascadia Code", monospace;
```

The typography system intentionally maintains a technical, engineering-oriented character throughout the platform.

# Local Development

## Prerequisites

```text
Node.js 18+
npm
Git
```

## Clone

```bash
git clone https://github.com/manikantac4/VybeAI.git
cd VybeAI
```

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## Production Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
